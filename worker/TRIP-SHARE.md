# 分享码部署

后端需要绑定 D1 数据库 `TRIP_SHARES`，运行 trip-share-schema.sql 初始化。尚未配置时接口返回 503；前端仍保留完整行程链接分享。

创建独立数据库后，将实际 ID 配置到 wrangler.toml 的 `[[d1_databases]]`，binding 为 `TRIP_SHARES`，再部署 Worker。沿用现有 AI_RATE_LIMITER，分享请求使用独立的 `share:` key 前缀。

分享码为随机6位字母数字字符串，排除 0/O/1/I，输入不区分大小写。使用 Web Crypto 均匀生成，数据库主键与原子 INSERT 防止并发覆盖，冲突最多重试8次。保存紧凑行程快照，7天后不可访问；每次创建时清理最多100条过期记录。持码者可访问；不能把码用于敏感信息的访问控制。

验证：创建分享码、另一浏览器导入、过期/无效码、限流、剪贴板拒绝、iOS Safari系统分享内拷贝。导入走原有只读分享预览，不直接覆盖本地草稿。
