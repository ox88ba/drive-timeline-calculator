# 自驾行程时间计算器

基于高德地图导航数据的自驾时间计算器

## 新版界面（预览）

`next/` 是重新设计的界面，与旧版并存，部署后访问 `/next/`：

- 一份行程数据 → 一次计算 → 一次渲染，不再由多层脚本改写 DOM
- 地点搜索、驾车路线、地图底图沿用现有 Worker 接口（`/api/poi`、`/api/route`、`/api/map-config`），高德 Key 仍只保存在 Worker
- 路线按段依次请求并缓存在本机；首次打开会自动带入旧版保存在同一浏览器里的行程
- AI 总评、分享长图、分享码暂未迁移，新版里会引导到旧版使用

本地开发（不调用高德、不消耗配额）：

```bash
node tests/next-mock-server.cjs
```

然后打开 http://localhost:8790/next/ 。假服务里搜索词含“失败”会返回错误，`/api/map-config` 固定返回 503，用于检查错误态和示意地图。
