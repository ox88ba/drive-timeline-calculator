# 自驾行程时间计算器

基于高德地图导航数据的自驾时间计算器

## 结构

- `index.html`、`app.css`、`app.js`：界面。一份行程数据 → 一次计算 → 一次渲染
- `api.js`：与 Worker 通信（POI 搜索、驾车路线、高德地图、分享码、AI、海拔、静态底图），高德 Key 只保存在 Worker
- `worker/`：Cloudflare Worker 接口
- `next/`：旧的预览地址，跳转回首页

旧版保存在浏览器里的草稿、方案、地点 AI 点评和海拔缓存会直接沿用；旧版生成的 `#trip=` 链接和 `?s=` 分享码都能打开。

## 本地开发

不调用高德和 AI、不消耗配额：

```bash
node tests/mock-server.cjs
```

然后打开 http://localhost:8790/ 。假服务里搜索词含“失败”会返回错误；地图配置和静态底图固定返回 503，用来检查示意地图；AI 接口返回固定的假内容。
